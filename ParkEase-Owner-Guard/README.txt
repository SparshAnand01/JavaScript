ParkEase Owner & Guard App

Files:
- index.html: main page
- styles.css: Drivers-only visual theme adapted for the Owner & Guard page
- app.js: Owner & Guard application functionality

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a browser.

The HTML links to styles.css and app.js, so no renaming or path changes are needed.
